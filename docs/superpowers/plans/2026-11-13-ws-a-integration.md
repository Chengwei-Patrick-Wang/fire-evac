# Workstream A — Integration, API, LLM and Tracer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the five workstreams plug together by shipping the plan tracer, the Gemini-backed API (batch, report, first pass), a precomputed static demo, and the submission text and video.

**Architecture:** FastAPI routes under `/api` wrap the scaffold's normalizer and sim and D's batch; `backend/llm` puts Gemini behind one `complete()` that returns `None` on any failure, so every feature has a fallback. The tracer is an SVG page in `frontend/src/tracer` whose geometry and export are pure TypeScript, so a script can push its output through the normalizer. `tools/precompute_demo.py` writes runs and batches into `frontend/public/demo/` for a static Netlify site that survives bad Wi-Fi.

**Tech Stack:** Python 3.12, FastAPI, google-genai, shapely, React + TypeScript (plain SVG, Zustand), Vite, tsx (check scripts), Netlify.

**Spec:** docs/superpowers/specs/2026-11-13-fire-evac-sim-design.md

## Global Constraints

- Contracts are spec §6 exactly (plan, building, scenario, run, batch `/v0`); `contracts/*.example.json` are the source of truth; only new optional fields; every JSON carries `"version"`; units are meters, coordinates floor-local, run coordinates rounded to 0.01 m, frames every 0.5 s.
- Traced plans: rooms drawn edge to edge on a 0.25 m grid (the normalizer insets each by 0.1 m); a door's `a`–`b` runs along its wall and `width` = |ab|; an exterior door sits in the outside wall (the normalizer adds the 2 m stub and the exit zone; never draw exits against a wall).
- API: FastAPI under `/api` with the §7.5 routes; runs saved in `data/runs/`; everything seeds from `scenario.seed`; batches and what-if comparisons use rule-based agents only; LLM crowd runs (`brain: "llm"`, up to ~150 agents) are showcases, precomputed and replayed from logged decisions.
- LLM: Gemini through `google-genai`; `GEMINI_API_KEY` and `GEMINI_MODEL` from `.env`; JSON-schema output, a timeout, `None` on failure; `LLM_PROVIDER=claude` reads `APP_ANTHROPIC_API_KEY`, never `ANTHROPIC_API_KEY`; keys stay in `.env`, never in a `VITE_*` variable. Fallbacks (§13): a template report, and the tracer without AI.
- Frontend: static `public/demo/*.json` listed in `public/demo/index.json`, or the API at `VITE_API_URL`; the demo survives bad Wi-Fi (static site, laptop backend, backup video); if run files are too big (§13): agent frames every 1 s, smoke every 5 s, fewer agents.
- Ethics: not a compliance tool, the fire model is labeled illustrative, no "panic" mode, no personal data, every data license credited in the app and on Devpost.
- UMass: the Student Union trace and everything derived from it stay in `data/private/`, out of the repo, static site, Devpost, slides and video; it is shown live from the laptop only; send Gemini public plans only.
- Hackathon mode: no TDD; run `python -m backend.smoke_test` before every push; stay in `backend/`, `frontend/src/tracer/`, `tools/`, `contracts/` (shared files get their own small PR); push hourly, PR every 2 h; never force-push, never push to `main`, never commit `.env` or `data/private/`.

## Review Focus

1. UMass-derived data reaching the repo, static site or Devpost: `from-plan` defaults to `data/private/` and only `public=true` writes `data/buildings/` (A1 smoke); `check_all.py` fails if `git grep -il umass -- data/buildings frontend/public/demo` hits (A1); precompute refuses private buildings (A5).
2. The tracer maps pixels wrongly (image y runs down, plan y runs up; each floor has its own scale; floors need a shared reference point): `check.ts` asserts `pxToPlan([0, H]) == [0, 0]`, 100 px = 5 m gives 0.05 m/px, and one physical point exports to the same coordinates on both floors (A2).
3. A trace the normalizer cannot use (no exterior door, a stair group on one floor, a door off every wall, duplicate ids, misaligned stairs) leaves people with no exit: `validatePlan` names each fault and `tools/check_tracer.py` pushes the good fixture through `plan_to_building` (A2).
4. Gemini returns junk or nothing (self-intersecting polygons, off-list types, invented numbers, timeout, no key): first-pass polygons are sanitized, report numbers are inserted by code, and `LLM_PROVIDER=off` exercises every fallback (A7 and A8 smoke).
5. A batch runs for minutes, crashes or returns the wrong shape: it runs off the request thread, a failure reports `status: "error"` instead of `running` forever, and the result has every batch/v0 key and a `why` on each `top` entry (A4 smoke).
