## Global Constraints

- Units are meters, coordinates floor-local; every JSON file carries `"version"` (`plan/v0`, `building/v0`); the examples in `contracts/` are the source of truth (§6).
- Contracts are frozen: never rename or remove a field; new optional fields are fine; `contracts/`, `AGENTS.md`, `requirements.txt` and `frontend/src/data/` change only through small PRs that A merges (§6, §11).
- plan/v0 room `type` is one of office, classroom, kitchen, dining, lounge, bedroom, lab, storage, restroom, corridor, lobby, stair, other; stair rooms carry a `group`, and the same group on consecutive floors means they connect (§6).
- Door `{id, a, b, width, fireDoor, state, rect?}`: `a`,`b` are the ends of the opening along the wall, `state` is open, closed or propped, `rect` is the opening's own footprint (a ring of 4 `[x, y]` points); a door in the outside wall is exterior (§6).
- building/v0 floor `{id, level, elevation, height, walkable[], rooms[], doors[], stairs[], exits[]}`: `walkable[]` is `{outer, holes}` rings (walls are their boundary); doors add `connects: [roomId, roomId | "outside"]` and `rect`; stairs `{id, group, room, polygon}`; exits `{id, name, door, polygon}` may be on any floor (§6).
- normalize: shrink rooms by half a wall (0.1 m for traced plans, 0 for IFC); each door reaches 0.2 m into the rooms on both sides (or uses its `rect`); each exterior door gets a 2 m stub and the exit polygon is the stub's far end; walkable = union(rooms, door rects, stubs); warn about disconnected pieces and unreachable rooms (§6).
- Never draw exit zones against a wall: JuPedSim then lets people out about 4× faster per meter (§6, `docs/context/07`).
- IFC path: run `inspect_ifc.py` first and pick the model with spaces on every storey and at least 2 stairs; footprints are triangles projected to 2D and unioned; doors come from `IfcDoor` footprints and `OverallWidth`; stairs are grouped by XY overlap across storeys; hand fixes go in `buildings/overrides/<id>.json` (§7.1).
- Credit every data source and license; data derived from UMass plans stays in `data/private/` (gitignored), never in the public repo, Devpost or video (§3, §12).
- Hackathon mode (AGENTS.md): no TDD; run `python -m buildings.smoke_test` before every push; small commits; never force-push or push to `main`; never commit `.env`, `data/raw/`, `*.ifc` or `data/private/`. Windows and macOS: use `pathlib`, no shell-specific code. B uses no randomness: the same input must give the same output (sort before iterating).

## Review Focus

1. **IFC in millimeters or feet:** geometry from `create_shape` is already in metres, but `OverallWidth` and `Elevation` are in model units. B2 asserts plan extents of 10–500 m and B3 asserts every door width is 0.6–3.0 m on the picked model.
2. **Spaces missing or not contained:** `get_container(space)` is `None` because spaces are aggregated into the storey. B2 asserts every kept floor has at least one room and the kept storeys are contiguous.
3. **Doors that overlap only one room (or neither):** door footprints are thinner than walls. B4 asserts every interior door's rect overlaps both rooms in `connects` by at least 0.01 m² on a thick-wall fixture and on the real building.
4. **Stairs that don't overlap across storeys:** B3 asserts at least 2 stair groups span 2 or more floors and no floor has two rooms in one group; B5 asserts the report flags a group that exists on one floor only.
5. **Exits on upper levels, and false ones (balcony doors, faces onto unmodeled corridors):** B4 asserts an upper-floor exterior door yields an exit on that floor, a diagonal-wall door gets a stub perpendicular to the wall, and a door facing an unmodeled space does not; B5 asserts the report lists upper-level exits.

### Task B2: IFC extraction I, storeys and room footprints (P0, target Sat 10 AM; aim for ~4 AM)

**Files:** Create `buildings/ifc.py`; modify `buildings/smoke_test.py`.

**Interfaces:** Consumes the picked IFC (path in `buildings/README.md`) and plan/v0 (§6). Produces `extract(path: str | Path, *, id: str | None = None, name: str | None = None, credits: str | None = None) -> dict` (plan/v0; doors and stairs arrive in B3) and the CLI `python -m buildings.ifc IN.ifc OUT_PLAN.json [--id ID] [--name NAME] [--credits TEXT]`. Defaults: `id` = slug of the file stem, `name` = IfcProject name or the stem, `credits` = `"IFC model <file name>; license: see buildings/README.md"`.

IFC facts (verified on IfcOpenShell 0.9.0.post1 with a millimetre model): `scale = ifcopenshell.util.unit.calculate_unit_scale(model)` is 0.001 for mm and 0.3048 for ft. Geometry from `create_shape` is **already in metres**: never multiply vertices by `scale`; only attribute values (`Elevation`, `OverallWidth`) are in model units and take `* scale`. Use `settings = ifcopenshell.geom.settings(); settings.set("use-world-coords", True)`, `shape = ifcopenshell.geom.create_shape(settings, element)`, `verts = np.array(shape.geometry.verts).reshape(-1, 3)`, `faces = np.array(shape.geometry.faces).reshape(-1, 3)` (a box gives 12 triangles; only the 4 top and bottom ones have XY area). Storey of an element: `get_container(e)`, else `get_aggregate(e)`, up to 5 times (`get_container(space)` is `None`).

- [x] `footprint(element) -> shapely geometry | None`: project each triangle to XY, drop those with area < 1e-9, `shapely.set_precision(tri, 0.001)` each, `unary_union`. Return `None` with a logged warning if `create_shape` raises or the result is empty.
- [x] Storeys sorted by `Elevation * scale` (fall back to the lowest z of their spaces). Keep storeys with at least one IfcSpace; raise `ValueError` naming the storey if the kept ones are not contiguous in the sorted list. Floors are `F1…Fn`, `level` 0…n−1, `elevation` relative to the lowest kept storey (3 decimals), `height` = next kept elevation − this one (top floor: the height below it; 3.5 if there is one floor).
- [x] Rooms: skip spaces with `PredefinedType == "EXTERNAL"` and footprints under 1.0 m². A footprint with several parts or holes becomes one room per simple polygon: cut each hole with `shapely.ops.split(poly, LineString([(minx - 1, y), (maxx + 1, y)]))` at the hole centroid's y, repeating until none is left; suffix the ids `a`, `b`, … Polygons are counter-clockwise rings with no repeated last point.
- [x] Names and ids: `name` = LongName, else Name, else `Space <n>`. `id` = `R` + Name stripped to `[A-Za-z0-9_-]` if unique in the building, else `R` + `GlobalId[-6:]` (Revit GlobalIds share their first characters). `type` = first match, on whole lowercase words (plural `s` allowed), in this order: stair; toilet, restroom, wc, lavatory, bath → restroom; kitchen; dining, cafeteria, cafe → dining; classroom, class, lecture, training → classroom; lab; bedroom, sleep, dorm → bedroom; storage, store, closet, janitor, mech, electrical, utility, shaft, riser → storage; lobby, vestibule, entry, foyer, reception; corridor, hallway, hall, circulation, passage → corridor; lounge, waiting, break; office, conference, meeting, exam; else `other`.
- [x] Finish: shift all x, y so the minimum over every room of every floor is 0 (meters, 3 decimals); `source: "ifc"`; `doors: []`. The CLI writes indented JSON and prints rooms and total area per floor.
- [x] **Verify:** `python -m buildings.ifc <PICK> data/raw/pick.plan.json`, then `python -m buildings.smoke_test` with a new `check_ifc()` called before the final `OK` (set `IFC_PATH` at the top of the file to the pick; if the file is missing it prints `SKIP ifc: file missing`). It asserts: `extract` raises no `ValueError` (kept storeys are contiguous); at least 1 floor; every floor has at least 1 room; elevations strictly increase; polygons are valid and hole-free; min x and min y are 0; plan extents are 10–500 m and every room area is 1–2000 m² (the mm and ft pin); then prints `OK`.

### Task B3: IFC extraction II, doors, stair rooms and groups (P0, target Sat 10 AM; aim for ~7 AM)

**Files:** Modify `buildings/ifc.py`, `buildings/smoke_test.py`.

**Interfaces:** Consumes B2's `extract` and `footprint`. Produces the same `extract(...)`, now returning floors with `doors[]` and stair rooms, plus the pure helper `group_stairs(floors: list[dict]) -> None` (sets `group` on the `type == "stair"` rooms in place; testable without IFC).

- [x] Doors: for each `IfcDoor` on a kept floor (storey as in B2): `fp = footprint(door)` (skip if `None`); `mrr = shapely.minimum_rotated_rectangle(fp)`; `u` = unit vector of its long axis (the wall direction), `n` = its normal, `c` = its centre. `W = OverallWidth * scale` if it is set and 0.5–4.0 m, else the long-axis length. `a = c - u*W/2`, `b = c + u*W/2`, `width = round(W, 2)`. `rect` = ring of 4 points centred on `c`: length `W` along `u`, depth (the footprint's short side + 2 × 0.15) along `n`. Grow the depth only, never the length, so the opening keeps its true width (this refines "buffer by 0.15 m", which would turn a 0.9 m door into a 1.2 m gap). `id` = `D` + `GlobalId[-6:]`, `name` = Name; `fireDoor` = `Pset_DoorCommon.FireRating` is non-empty (`ifcopenshell.util.element.get_psets(door)`); `state` = `"closed"` if fireDoor else `"open"`.
- [x] Stair rooms: B2 already makes `type == "stair"` rooms from spaces named like stairs. For each `IfcStair` (and each `IfcStairFlight` with no `IfcStair` parent): footprint = union of its own shape and the shapes from `ifcopenshell.util.element.get_decomposition(stair)` (skip parts that fail; skip a total area under 2 m²). If no stair room on its storey overlaps at least 30% of that footprint, add a room `{id: "S" + GlobalId[-6:], name: "Stair", type: "stair", polygon: footprint.buffer(0.3, join_style="mitre") exterior ring}`; do the same on the next kept floor up (a stair belongs to its lower storey, so the upper floor has no object). Apply the final coordinate shift to doors and stairs too.
- [x] `group_stairs(floors)`: for each pair of consecutive floors compute overlap areas between their stair rooms and pair them greedily by descending overlap, each room used at most once per pair of floors, only if the overlap is at least 0.3 × the smaller room's area; matched rooms share a group (chained across floors); group ids `S1`, `S2`, … ordered by the lowest-floor room's centroid (x, then y); unmatched stair rooms get their own group (B5 reports them). Call it at the end of `extract`.
- [x] Stair doors: any door whose `rect` intersects a stair room gets `fireDoor: True`, `state: "closed"` (the propped-door what-if needs closed stair doors in the baseline). `source: "ifc"`, `credits` as in B2.
